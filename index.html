🐸 Fwoggy-Flick

A Physics-Based Tile Hookshot Game

Grab tiles with your tongue, launch them as projectiles, and survive the endless cascade!

Play Demo

How to Play

🎮 Controls

  • SPACEBAR Extend tongue / Shoot tile / Retract
  • P or ESC Pause game
  • Auto-Aim: Frog rotates automatically (-70° to +70°)

🎯 Game Mechanics

  1. Extend: Shoot tongue upward to grab tiles
  2. Grab: Tongue collides with and captures tiles
  3. Retract: Pull tile back to your mouth
  4. Load: Hold tile ready to launch
  5. Launch: Fire tile as projectile to destroy others

🎲 Tile Types

🟢

Normal Tile

Basic tile • Grabbable • Destroyed on hit

🟤

Hardened Tile

2 HP • Reflects projectiles • Cannot be grabbed

💣

Bomb Tile

Explodes in 3×3 area • Chain reactions

🧊

Ice Tile

Freezes grid scrolling • 5 second duration

🏆 Objective

Survive as long as possible! The grid continuously scrolls down at increasing speed. Destroy tiles before they reach the bottom and damage you (3 HP). Earn 10 points/second survived + 10 points per tile destroyed. Create chain reactions for massive combos!

About the Project

Fwoggy-Flick is a tile-based physics game built entirely from scratch using vanilla JavaScript and the Canvas API—no game engines, no physics libraries. Every system, from collision detection to state management, was hand-implemented to deepen understanding of game development fundamentals.

🔧 Technical Highlights

⚙️

Custom Physics Engine

Hand-implemented collision detection using the Separating Axis Theorem (SAT) for pixel-perfect collision between rotating convex polygons. Two-phase detection system: AABB broad-phase for performance, SAT narrow-phase for accuracy.

🎭

Finite State Machine (FSM)

Clean state management pattern for both Player (IDLE, EXTENDING, RETRACTING, LOADED, DEATH) and GameManager (MENU, PLAYING, PAUSED, GAMEOVER). Prevents edge cases and enables scalable behavior control.

🏗️

Object-Oriented Architecture

Inheritance hierarchy with base GameObject class providing shared collision geometry. Polymorphic onHit() and onDestroy() methods enable tile-specific behaviors. Composition over inheritance where appropriate.

🎨

Sprite System & Rendering

JSON atlas-based sprite rendering with frame animation support. Custom game loop using requestAnimationFrame with fixed deltaTime for time-independent physics. Transform matrix operations for rotation and translation.

🔀

Procedural Content Generation

Weighted random tile spawning system with infinite scrolling grid. Dynamic difficulty scaling as speed increases over time. Efficient tile recycling prevents memory leaks during extended play sessions.

💾

Data Persistence

LocalStorage integration for leaderboard system with score tracking and session management. Maintains best scores across sessions for player retention and progression.

Computer Science Fundamentals

  • Algorithms: Implemented SAT collision detection from academic resources
  • Computational Geometry: Vector mathematics, dot products, polygon projections
  • Data Structures: Grid-based spatial management, object pooling concepts
  • Performance Optimization: Two-phase collision detection, early exit strategies

Software Engineering

  • Design Patterns: Finite State Machine, Strategy Pattern (polymorphic behaviors), Module Pattern
  • Clean Code: Separation of concerns, single responsibility principle, consistent naming
  • Architecture: OOP with inheritance hierarchies, composition for complex behaviors
  • Modularity: ES6 modules with clear dependencies and exports

Game Development

  • Game Loop Architecture: Update/render separation, fixed timestep physics
  • Physics Simulation: Velocity-based movement, projectile trajectories, bounce mechanics
  • State Management: Preventing impossible transitions and edge cases
  • Canvas Rendering: Low-level 2D graphics programming, transform matrices

Problem-Solving & Self-Learning

  • Vanilla JS Mastery: Built complete game without framework dependencies
